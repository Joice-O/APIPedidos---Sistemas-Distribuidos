# Checklist final de entrega

- [ ] Preencher nome completo, turma, RA e URL do repositório no `README.md`.
- [ ] Preencher os mesmos dados em `ENTREGA_TEAMS.txt`.
- [ ] Criar um repositório GitHub na sua própria conta.
- [ ] Enviar todos os arquivos deste projeto para o repositório.
- [ ] Em uma máquina com Docker, executar `docker compose up -d --build`.
- [ ] Confirmar `http://localhost:8000/health` retornando `{"status":"ok"}`.
- [ ] Confirmar o Swagger em `http://localhost:8000/docs`.
- [ ] Criar um pedido e consultar o mesmo pedido.
- [ ] Executar `docker compose restart pedidos` e confirmar que o pedido continua existindo.
- [ ] Criar a tag `APIPedidos-1-final` somente depois da versão final estar no GitHub.
- [ ] Executar `git push origin APIPedidos-1-final`.
- [ ] Entregar individualmente no Teams a URL do seu próprio repositório e os dados de todos os integrantes.
